# Security Policy

ConnectorKit handles OAuth tokens and credentials, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability") on this repository.

Include a description, reproduction steps and the affected version. You can expect an initial response within a few days.

## Scope

In scope: token storage and encryption, OAuth flow handling (`state`, PKCE), secret leakage in logs or errors, input validation bypass.

## Supported versions

Pre-0.1: no released versions are supported yet.
